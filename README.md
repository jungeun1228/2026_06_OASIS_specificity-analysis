# 2026_06_OASIS_specificity-analysis

To be updated soon (ongoing project)

1. Data processing
   - Derived speciation information of individual chemicals in OASIS consortium using PlayMolecule AcepKa: predicted speciation of chemicals at pH 7.4 and calculated neutral, positive, negative, and zwitterionic fraction
   - Combined three data frame: OASIS consortium dataset (chemical list), Supplementary Table from Ewald et al. 2026 (POD of cytotoxicity and cell painting assays), physicochemical property table containing speciation fraction, etc.  
   - Predicted baseline toxicity of individual chemicals using QSAR model and grouped the chemicals based on specificity
2. QC
3. PCA/ UMAP
   - Identify narcosis patterns based on channel-wise DINO profile patterns (ongoing)
